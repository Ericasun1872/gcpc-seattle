# 시애틀 주은혜교회

Official visitor site for **시애틀 주은혜교회** (Grace Community Presbyterian Church - Seattle).

Korean default, English toggle. Five pages: Home, 예배 안내, 교회소개, 설교, 연락처.

No 게시판 / notice CMS. Living updates stay on [YouTube](https://www.youtube.com/@gcpc.seattle) and [Instagram](https://www.instagram.com/gcpc.seattle).

## Edit times or address

Change `js/church.js` only. Do not invent parking, doors, kids ministry, phone, giving, or a domain.

## Preview locally

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080/`.

Seasonal watercolor follows the calendar (spring / summer / autumn / winter). Preview a season with `?season=winter`.
